NOIR - Car Website

NOIR is a modern and interactive car website designed to provide users with a premium vehicle browsing experience. It features smooth scroll animations, detailed car information, and an AI-powered chatbot for booking test drives.

Test drive booking details are automatically stored in a spreadsheet, making appointment management simple and efficient.

Key Features
🚗 Modern car showcase
🤖 AI chatbot for test-drive booking
📋 Automatic test-drive data storage in a spreadsheet
🎞️ Smooth scroll animations
📱 Responsive and user-friendly design
✨ Clean and premium UI

NOIR combines modern web design, AI assistance, and automated booking management into one platform.
